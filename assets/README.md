# Local third-party assets

- Normalize.css 8.0.1: https://github.com/necolas/normalize.css (MIT; see licenses/normalize-LICENSE.md).
- Milligram 1.4.1: https://github.com/milligram/milligram (MIT; see licenses/milligram-LICENSE).
- Montserrat variable font, Latin and Latin Extended subsets: Google Fonts CSS API (v31), https://fonts.google.com/specimen/Montserrat (SIL OFL 1.1; see fonts/OFL.txt).

Fonts and stylesheets are served locally. No package manager or build step is required.
